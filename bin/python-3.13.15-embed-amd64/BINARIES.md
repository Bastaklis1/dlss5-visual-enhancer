# Embedded Python environment

The complete `python-3.13.15-embed-amd64` runtime is intentionally not included in this GitHub copy. This Markdown file replaces the entire bundled environment.

The omitted content is the portable 64-bit Python 3.13.15 distribution, including:

- the Python interpreter, standard library, extension modules, and runtime libraries;
- installed packages used by the application;
- package command launchers under `Scripts`;
- native media, image, numerical, and machine-learning dependencies.

Download or rebuild the embedded Python environment with the application's required packages before running the program.
