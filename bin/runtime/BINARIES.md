# DLSS and ReShade runtime files

The proprietary or prebuilt Windows runtime files are intentionally not included in this GitHub copy.

- `dxgi.dll` — ReShade/DXGI proxy that loads the visual-enhancement runtime.
- `nvngx.dll` — NVIDIA NGX runtime component.
- `nvngx_dlss.dll` — NVIDIA DLSS Super Resolution runtime component.
- `nvngx_dlssnr.dll` — NVIDIA DLSS Ray Reconstruction runtime component.
- `renodx-dlss5.addon64` — RenoDX/ReShade add-on that provides the DLSS 5 visual-enhancement integration.
- `ReShade.ini` — ReShade configuration used to load and configure the visual-enhancement runtime.

Restore the matching runtime files before running the program. Use only files you are licensed to redistribute.
